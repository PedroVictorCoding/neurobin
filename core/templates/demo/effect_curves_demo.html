About Effect Curves
Effect Shapes
  • Bell: Classic onset → peak → decline
  • Ramp: Gradual rise then sharp decline
  • Flat-top: Rise → plateau → decline
  • Custom: User-defined profile
Key Parameters
  • Onset: Time before effects begin
  • Peak Min/Max: Duration of peak effects
  • Duration: Total effect time
  • Half-life: For exponential decay
Visualization Features
  • Dose Scaling: Height based on dose amount
  • Time Overlay: Multiple compounds on timeline
  • Interactive: Hover for details
  • Responsive: Works on all devices
